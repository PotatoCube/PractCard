# PractCard
Практика ТПУ 1 курс. Карточки для заучивания слов на С++
# Учебный проект: Приложение "Карточки для заучивания слов" на C++

# Требования к системе для сборки

Системные требования:
*   Операционная система: Windows 10 / 11 (64-bit)
*   Visual Studio Code или Qt Creator
*   Компилятор: GCC 11.0+ 
*   CMake (версия 3.16 или выше)
*   Дополнительные библиотеки: Qt 6.x (модули `Core`, `Gui`, `Widgets`)

---

# Последовательность сборки и запуска приложения

Вариант 1. Сборка через терминал (MSYS2 UCRT64)
1. Откройте терминал **MSYS2 UCRT64** и перейдите в корневую директорию проекта:
   ```bash
   cd /path/to/project
   ```
2. Создайте отдельную директорию для сборки и перейдите в неё:
   ```bash
   mkdir build
   cd build
   ```
3. Сгенерируйте файлы конфигурации Make-файлов с помощью утилиты CMake:
   ```bash
   cmake -G "MinGW Makefiles" ..
   ```
4. Скомпилируйте программный код утилитой GNU Make:
   ```bash
   mingw32-make
   ```
5. Запустите готовое скомпилированное приложение:
   ```bash
   ./FlashcardsApp.exe
   ```

Вариант 2. Сборка через Visual Studio Code
1. Откройте корневую папку проекта в VS Code.
2. При первом открытии расширение **CMake Tools** предложит выбрать набор инструментов (Kit). Выберите компилятор **GCC (UCRT64)** (путь `C:\msys64\ucrt64\bin\g++.exe`).
3. Убедитесь, что в файле `.vscode/settings.json` указаны верные пути к префиксу библиотек Qt6:
   ```json
   {
       "cmake.configureSettings": {
           "CMAKE_PREFIX_PATH": "C:/msys64/ucrt64"
       }
   }
   ```
4. Выполните конфигурацию проекта: нажмите `Ctrl + Shift + P` -> выберите команду `CMake: Delete Cache and Reconfigure`.
5. Нажмите кнопку **Build** на нижней панели (или клавишу `F7`) для компиляции проекта.
6. Нажмите кнопку **Run** (или `Shift + F5`) для запуска программы поверх окон.
